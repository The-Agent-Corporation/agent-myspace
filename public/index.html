⚖️ For Law Firms & Legal Practice

1. Roscoe

An AI paralegal for personal-injury law firms.

Very Active • Oct 22, 2026 🔒 Private Repo (aaron-agent-corporation/roscoe)

Roscoe keeps an organized digital file for each case (FirmVault), sorts incoming mail and medical or court documents, and works through case tasks step by step. It is now learning to do Kentucky and Sixth Circuit legal research and draft memos where every single citation, quote, and case fact has to trace back to a verified source. An attorney approves the research plan and key checkpoints before anything moves forward.

Who it's for: Small personal-injury firms that drown in paperwork and want hours back without ever letting an AI invent facts or act unchecked.
Current status: Flagship project. Over 100 pull requests merged in October 2026 alone; latest update Oct 22, 2026.
For curious techies: Python and TypeScript, durable Postgres-backed workflows with mandatory human approval gates, an attorney web console, and adversarial multi-agent code review.
🔒 Codebase is private 🔓 Open-Source Companion Repo (roscoe-companion) →

2. Jury Trial Search (Verdict Intelligence)

Search past jury verdicts the way you search for flights.

● Live on Render Active • Oct 16, 2026 🔒 Private Repo

A searchable library of historical Kentucky trial outcomes. Lawyers can filter by case type, injury, county, and verdict range in a clean travel-style search interface, compare cases side by side, and ask an inline research assistant questions about the results. Case captions and outcomes are audited against the original court trial reports.

Who it's for: Trial lawyers valuing a claim or deciding whether to take a case to a jury. Knowing what real juries actually awarded is a huge advantage.
Current status: Active subscriber alpha deployed live on Render. Last code update Oct 16, 2026.
For curious techies: Python backend on Postgres with a semantic layer, travel-style filter UI, and an AI assistant that computes statistics over the exact filtered cohort.

3. VoiceDocs

A browser document editor where you and an AI edit together by talking and pointing.

Working Prototype • Oct 16, 2026 🔒 Private Repo

Open a draft or import a Microsoft Word file, point at a paragraph or highlight a phrase, and say out loud what you want changed. The AI proposes grounded edits right in the margin that you can accept or reject, and when you finish, it exports your original Word document back out with tracked changes intact.

Who it's for: Lawyers and professionals who spend all day revising letters, contracts, or briefs and find it faster to talk and point than to type.
Current status: Working prototype with Word numbering and tracked-revisions export. Last update Oct 16, 2026.
For curious techies: TypeScript web app with Yjs collaborative state, PDF reference viewer, voice capture + transcription, and Claude via Anthropic/OpenRouter with automatic model fallback.
Repo: aaron-agent-corporation/voicedocs (Private)

4. Transcript Studio

Turn courtroom, deposition, and meeting recordings into clean, speaker-labeled transcripts.

● Live on Render (Invite-Only) Working Tool • Oct 11, 2026 🔒 Private Repo

Drop in audio or video recordings and it transcribes them, separates and matches speaker voices across recordings, and gives you a synchronized review workspace where clicking any word seeks the audio to that exact second. When you're done reviewing, it exports a clean PDF with timestamps that link back to the recording.

Who it's for: Legal teams and researchers who need an accurate, searchable record of hearings, interviews, or multi-day recordings without paying rush court-reporter rates for every clip.
Current status: Working local and cloud tool hosted on Render (invite-only login). Last update Oct 11, 2026.
For curious techies: Python server, ffmpeg + Whisper large-v3-turbo (local or Modal cloud GPUs), Resemblyzer speaker embeddings, and a browser review queue.

💼 Business & Office Tools

5. AI IT

An AI IT department in a box for small offices with no IT staff.

Active Build • Oct 22, 2026 💻 Mac Workspace (_general-business-projects/ai-it)

A lightweight helper runs on each Mac or Windows PC in an office and reports machine health, printer status, and errors to a central dashboard. When something breaks, the AI diagnoses the issue from real machine data and proposes a fix from a vetted catalog, running it only after a human clicks approve. It also verifies that built-in security (XProtect, Defender, firewall) and backups are actually working.

Who it's for: Small law firms, medical offices, and households that don't have a dedicated IT person and want problems caught early and fixed safely.
Current status: Active build started in October 2026; Go agent, fix catalog, and web dashboard committed Oct 22, 2026.
For curious techies: Go agent on macOS and Windows, osquery telemetry, ARP/mDNS/IPP network discovery, a canonical JSON procedure catalog with checkpoints, and a React dashboard.

7. LimitSwitch

One dashboard for all your AI subscriptions, usage caps, and API keys.

● Live Cloud App Working App • Oct 16, 2026 💻 Mac + Render Cloud

8. Conversational Memory System

Long-term, resumable thread memory so AI assistants remember past work.

Active • Oct 22, 2026 🔓 Public Repo

Most AI chats forget everything the moment you open a new window. This system treats conversation threads as durable objects, summarizes them in the background, groups related topics, and injects the right past context when a topic comes back up weeks later.

Who it's for: Anyone building or using personal AI assistants that need continuity across days and projects without blowing up model token costs.
Current status: Active open-source repo; completed live OpenRouter model bake-offs and semantic summarizer pipeline in Oct 2026 (last push Oct 22, 2026).
For curious techies: Python memory pipeline with sidecar summarization (defaulting to Claude Haiku 5.5 via OpenRouter), strict spend ledgers, and anchor-based surfacing.
💻 View Public Code on GitHub (The-Agent-Corporation/conversational-memory-system) →

9. Code-KG

A living map of a software codebase that AI coding agents read before making changes.

Working Tool • Oct 21, 2026 🔓 Public Repo (MIT)

AI coding agents often break things because they only look at one file at a time. Code-KG builds a structured knowledge graph of how functions, files, and architecture concepts connect across a repository, checks for drift on every git commit, and feeds that map to agents before they edit code.

Who it's for: Software builders who run AI coding agents and want fewer blind edits and better architectural awareness.
Current status: Working open-source CLI and Claude plugin. Restored to clean knowledge-graph + Graft core on Oct 21, 2026.
For curious techies: TypeScript CLI and MCP server using tree-sitter source intelligence across 20+ languages, wiki-link markdown nodes, embeddings search, and git hooks.
